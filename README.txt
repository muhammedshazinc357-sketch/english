SpeakEasy — Learn English Through Malayalam

HOW TO OPEN
1. Extract this ZIP.
2. Keep index.html, styles.css, and script.js together in the same folder.
3. Open index.html in a modern browser and click CONTINUE.

FEATURES
- Welcome screen and Continue button
- Dark and day themes
- Malayalam-to-English online translation with Google Translate fallback
- Everyday phrases, self-introduction, questions, and travel English
- English text-to-speech listening practice
- Optional speech recognition in supported browsers
- Short multiple-choice quiz
- Responsive mobile and desktop design

NOTES
